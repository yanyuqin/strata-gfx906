# gfx906 MMQ 实测（2026-11-17 02:00，amd52）

目的：核实 "MI50 没有 MMQ 预填充" 是硬件/理论限制，还是构建开关选择。
结论：**能编、能跑、结果正确；但比 Strata 自有 fused 内核慢 5%（5K），21K 持平。**

## 1. 构建

- 源：`~/port/mi50-0214`（v0.2.14.1 + rdna3 4 提交），ROCm `/opt/rocm715-gfx906`，clang 23.0.0git
- 目录：`~/port/mi50-0214/build-906-0214-mmq`
- 关键参数（与生产构建只差 MMQ 两项）：

```
-DSTRATA_HIP_GFX906=ON -DSTRATA_ENABLE_HIP=OFF -DSTRATA_ENABLE_CUDA=OFF -DSTRATA_BUILD_TESTS=OFF
-DSTRATA_MMQ=ON -DSTRATA_PREFILL_MMQ=OFF
-DCMAKE_HIP_ARCHITECTURES=gfx906
```

`STRATA_PREFILL_MMQ` 必须 OFF：CMakeLists:172 要求 `STRATA_ENABLE_HIP=ON`，与 gfx906 的 CUDA 分支互斥。
gfx906 的 MMQ 入口是 `STRATA_MMQ=ON`；`cuda.cmake:277` 会自动 `PUBLIC STRATA_PREFILL_MMQ=1`。

- `strata_mmq` 目标：58 步，24 个 mmq-instance（q2_0 / iq2_xxs / iq2_xs / iq2_s / iq3_xxs / iq3_s / iq4_nl / iq4_xs / q8_0 / q4_k / q5_k / q5_1 / q6_k + tq2_t / tqk6 / tqk7 / tqp5 / tqp6 / tqp7），**0 error**
- 完整二进制：`strata` **41,968,448 B**（无 MMQ 版 25,409,248 B，差 16.5 MB = MMQ 内核）
- 启动 ready：137 s（无 MMQ 版 161 s，含 `--mtp-q4 all` 量化）

## 2. 同二进制 A/B（只切 STRATA_MMQ_KQ）

配置 `cfg-arm-mmq.json` = `cfg-mi50-final.json` 只换 exe；参数 `--prefill 2048 --mtp-q4 all`，
2×MI50（ROCR 0,2 → HIP 0,1），`taskset -c 0-7,16-23`，821 语料 + nonce，128 tok，1 预热 + 3 测。

| 臂 | 5K prefill | 5K decode | 5K TTFT | 21K prefill | 21K decode | 21K TTFT |
|---|---|---|---|---|---|---|
| KQ=1（llama.cpp MMQ） | 492.9 | 64.1 | 9.353 s | 662.6 | 68.0 | 26.927 s |
| KQ=0（dequant+FP16） | 289.7 | 62.4 | 15.910 s | 412.6 | 69.1 | 43.243 s |
| 生产构建（MMQ=OFF，自有 fused） | 518.5 | 66 | 8.892 s | 661.8 | 65.4 | 26.959 s |

- MMQ vs FP16：**+70%**（5K）/ **+61%**（21K）——MMQ 确实生效，decode 不变说明结果正确
- MMQ vs 自有 fused：**−5.0%**（5K）/ 持平（21K）
- 5K 三 rep 抖动 <0.5%（492.9 / 492.2 / 493.9），差异真实

## 3. 为什么不能两者兼得

`src/prefill/prefill.cpp:204`：
```cpp
#if defined(STRATA_PREFILL_FUSED) && !defined(STRATA_PREFILL_MMQ)
#define STRATA_PF_OWN_ONLY 1
```
MMQ 构建会编译掉 Strata 自有 fused/int8 prompt 内核（P4-SPLIT 互斥），所以同一二进制里只能二选一，
而自有内核本来就快 5%。

## 4. 硬件侧

- gfx906 有 `V_DOT4_I32_I8` → `__builtin_amdgcn_sdot4`（`src/split/src/qdot.cuh:45-48` 白名单含 `__gfx906__`）
- `vendors/hip.h:184-192`：`__gfx906__ → GCN5 → GCN`；`mmq.cuh:261-275` 有 `#ifdef GCN → get_config_gcn`
- 无 MFMA（gfx908+）、无 WMMA（RDNA3/4）→ 只能走 dp4a 通用 tile，能用但不是最优
